# Security Policy

## Supported versions

Bettor Desktop is in early development. Security updates target the current
`main` branch. Packaged releases are not currently published or supported.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use the
repository's private GitHub Security Advisory reporting feature when it is
enabled. Otherwise, contact the repository owner privately through their
GitHub profile and ask for a secure reporting channel.

Include the affected version or commit, operating system, reproduction steps,
impact, and any suggested mitigation. Allow time for confirmation and a
coordinated fix before public disclosure.

Never include credentials, betting-account information, tokens, or real
bet-log data in a report. Use minimal synthetic examples and redact screenshots
and logs. This project does not need access to a betting account to reproduce a
valid report.
