Understand the price of variance.

Bettor Desktop brings betting calculators, simulations, reference material, and a local bet log into one open-source desktop workspace. The math runs in Rust; your records stay on your machine.

Follow on GitHub Run it locally

No packaged downloads yet. Follow the repository or build the current work from source.

The core idea

The same edge can produce a very different ride.

A modest favorite and a longshot can have the same expected value while carrying very different variance, drawdowns, and sample-size demands. Bettor Desktop makes those consequences visible instead of reducing every decision to one EV number.

Built for inspection

Tools for the number and the uncertainty around it.

Calculation and analysis

Convert and compare odds, remove vig, inspect expected value, size stakes, and explore common market scenarios.

Variance and simulation

Explore outcome ranges, drawdowns, risk of ruin, bet mixes, and reproducible simulated seasons.

Local bet log

Track bets and closing prices in a SQLite database stored in your operating system’s app-data directory.

Bundled reference

Read the concepts behind the outputs inside the app, without depending on a hosted knowledge base.

Follow along

Run the current source.

Install stable Rust, Node.js 22 or newer, pnpm, and the Tauri prerequisites for your operating system.

git clone https://github.com/WalrusQuant/bettor-desktop.git
cd bettor-desktop
pnpm install
pnpm tauri dev

# Verify the project, then create a platform bundle
pnpm verify
pnpm tauri build
Early development: there are no packaged releases or stability guarantees yet. Expect breaking changes while the project is built in public.

Privacy and responsibility

Your data stays local.

  • Core calculators and the bet log are designed to work locally; no account is required.
  • Bet records are stored on your device. Back up or remove the app-data database according to your own needs.
  • This software is an educational analysis tool, not financial advice and not a promise of profit. Gambling involves risk; follow local laws, set limits, and seek help if gambling stops being recreational.
